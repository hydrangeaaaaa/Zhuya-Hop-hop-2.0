# 逐亚 Hop Hop 2.0

这是从原版独立复制并优化的 **2.0 版本**；不会覆盖原来的
`Zhuya-Hop-Hop` 仓库或网站。

## 2.0 手机性能与音效优化

- Canvas 内部分辨率按实际显示宽度计算，并将设备像素比上限设为 1.5，避免手机为不可见像素做过量绘制。
- 大尺寸 PNG 在加载阶段预缩放到接近实际绘制尺寸；原始素材文件保持不变。
- 镜头渲染加入帧间插值，减少滚屏时的阶梯感。
- 平台、怪物、奖章、子弹和特效增加屏外裁剪；高频数组清理由反复创建新数组改为原地压缩。
- 猫/狗螺旋桨和御剑飞行循环音效改为无缝、轻量的 44.1 kHz 单声道 WAV，支持短淡入淡出且同类循环不会重复叠加。
- Web Audio 优先解码真实 WAV，失败时才使用程序生成的后备音效；HTML Audio 路径不再放大低音量请求。

完整验证数据见 [`PERFORMANCE-REPORT.md`](PERFORMANCE-REPORT.md)。

手机端优先的竖屏跳跃网页游戏。项目延续
[`kubowania/Doodle-Jump`](https://github.com/kubowania/Doodle-Jump) 的自动跳跃、
落台反弹、向上滚屏和无限平台生成机制，并保留上游 MIT 授权与作者署名。

## 运行

在本目录启动任意静态文件服务器，例如：

```powershell
python -m http.server 4173
```

然后打开 `http://127.0.0.1:4173/`。手机重力感应通常要求 HTTPS；拒绝权限或
设备不支持时，游戏会自动使用触控：左侧移动、右侧移动、中间射击。

## 当前玩法

- Canvas 2D 渲染，1/60 秒固定物理步长，浮点世界坐标和 swept landing。
- 普通自动跳跃、屏幕横向穿越、单向向上镜头和 guaranteed route 平台生成。
- 白/棕/黄手绘平台、蓝色断裂平台和少量移动平台。
- 稍大且贴台阶的拖鞋/吉他七帧高弹弹簧、贴近可达落点的猫/狗螺旋桨、醒目的馒头/斧子护盾和御剑飞行。
- 弹簧、护盾、螺旋桨和御剑平台上方保留纵向净空，下一平台强制向侧面错开，也不生成贴身怪物或叠放奖章；猫狗拾取碰撞区额外放宽。
- 独立奖章奖励、三种怪物和双帽尖汇聚射击。
- 重力感应、固定角色的多点触控、键盘操作、音效总开关与无重复监听重启。

## 生成平衡

完整概率阶段的主属性池为：普通 78%、断裂 5%、移动 4%、弹簧 5%、螺旋桨
3%、护盾 3%、御剑 2%。一个平台最多一个主属性，受冷却或同屏上限阻止时直接
回退普通平台。奖章独立为 14%，每枚 +50。前 20 个平台渐进解锁。
护盾总概率仍为 3%，其中大斧子约占 60%、馒头约占 40%。

## 主要文件

- `index.html`, `style.css`, `index.js`：页面和生命周期。
- `js/config.js`：集中配置、角色表和素材表。
- `js/game.js`：物理、生成、状态、碰撞和 Canvas 渲染。
- `js/audio.js`：首次 START 手势解锁；猫狗使用轻巧旋翼空气脉冲，御剑使用柔和风声，无背景歌曲和低频嗡鸣。
- `tools/prepare_assets.py`：确定性透明处理、弹簧/护盾小撇清理和平台调色。
- `UPSTREAM.md`, `LICENSE`：上游来源和 MIT 授权。
