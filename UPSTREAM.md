# Upstream project

This game continues from **kubowania/Doodle-Jump**, a vanilla JavaScript,
HTML, and CSS Doodle Jump clone by Ania Kubow:

https://github.com/kubowania/Doodle-Jump

The original automatic jump, top-only landing, platform recycling, upward
scrolling, and endless progression concepts remain the gameplay foundation.
The rendering and timing layer was refactored from DOM positioning and several
intervals to Canvas 2D with a fixed physics timestep because this edition adds
mobile tilt, moving and breaking platforms, animated springs, power-ups,
enemies, projectiles, and smooth state transitions.
